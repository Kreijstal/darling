# Generated public SDK skeletons

This directory is generated by `tools/generate-public-sdk-skeleton.py`. It contains link/load skeletons for macOS exports belonging to public SDK frameworks for which Darling has no existing framework target. Header declarations classify public C and Objective-C API; remaining TBD exports are retained as opaque linker symbols.

When a public TBD assigns its API to a private runtime provider, the provider is emitted at that real install name and remains associated with the public header component in the manifest.

Do not implement behavior here. Move a framework into the normal Darling source tree when implementation begins, then regenerate; the framework will automatically disappear from this directory. See `manifest.json` for exact provenance, counts, omissions, and ABI approximations.

Regeneration requires the compressed TBD export and header declaration catalogs produced by the `darling-testsuite` macOS SDK harvest:

```sh
python3 tools/generate-public-sdk-skeleton.py \
  --tbd-catalog /path/to/tbd-macos-exports.json.gz \
  --header-catalog /path/to/header-api-declarations.json.gz \
  --sdk-label 'macOS SDK version and build'
```
